# BioSocrates S3 — 6 Legends | Agentic AI for Drug Discovery

An autonomous multi-agent AI system that accelerates preclinical drug discovery. Built to mimic the workflow of a real pharma research team.

**🧬 What it does:**
- Agent 1 — Literature Miner: Scans PubMed & research papers
- Agent 2 — Molecule Designer: Proposes novel compounds
- Agent 3 — Toxicity Predictor: Filters for safety
- Agent 4 — Synthesis Planner: Creates lab-ready protocols
- Agent 5 — Clinical Strategist: Maps trials
- Agent 6 — Socrates (Orchestrator): Ethical reasoning & decision

**💻 Tech:** Agentic AI, LLMs, Multi-Agent Orchestration, BioNLP
